# Week 7 Weekly Assessment – RAG Policy Q&A Assistant

This project contains four task folders matching the assessment. Open this folder in VS Code. Install dependencies with `python -m pip install -r requirements.txt`. Read each task README for commands. Add credentials only to a local `.env` file; never commit it.

Tasks: `task1` RAG pipeline and fallback; `task2` advanced retrieval; `task3` citations and API; `task4` golden dataset and RAGAS evaluation.
